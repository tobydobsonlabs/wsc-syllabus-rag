# Sample corpus (synthetic)

These notes are **fictional fixtures**, written only so the public repo can run the
ingest -> retrieve -> answer pipeline without redistributing the real World Scholar's Cup
material (which is copyright-sensitive and lives outside this repo).

Nothing here is a real WSC fact. Names, sections, works, and years are invented. To run against
the real syllabus, point `INGEST_SOURCE_DIR` at a local WSC knowledge base; that content is never
committed (see `.gitignore`).
